# 🏆 Treasure Quest

Treasure Quest is a 2D platformer built with the Godot Engine. Players navigate three handcrafted levels, collect coins and gems, avoid enemies and hazards, and reach the exit while managing their health.

## 🎮 Play the Game

**Play online:** https://veronica-foltz.itch.io/treasure-quest

## ✨ Features

- Three playable levels

- Enemy AI (frog, bee, and fly)

- Coin and gem collection

- Health system with hearts

- Settings menu

- Moving enemies and hazards

- Persistent coin, gem, and health tracking between levels

- Final score screen

- Web deployment via itch.io

## 🛠️ Built With

- Godot 4

- GDScript

- itch.io

## 🎮 Controls

### Desktop

- **Move:** Left / Right Arrow Keys

- **Jump:** Spacebar

- **Crouch:** Down Arrow

### Mobile

- On-screen touch controls
